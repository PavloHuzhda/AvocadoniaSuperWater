# Avocadonia Launch Page

A premium, responsive one-page website built with pure HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in any modern browser.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

The website has no backend, build tools, frameworks, cookies or analytics.
